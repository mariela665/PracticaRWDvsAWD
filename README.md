# Práctica RWD vs. AWD

**Descripción:** Catálogo web de componentes de computadora para comparar el diseño responsivo (RWD) y el adaptativo (AWD).

**Tecnologías:** HTML, CSS, JavaScript, Node.js y Express.

**Instalación y ejecución**

**RWD:** Abrir `responsive/index.html` en el navegador.

**AWD:** Abrir una terminal en la carpeta `adaptive` y ejecutar:

```bash
npm install
node server.js
```

Después, abrir en el navegador la dirección local configurada en el servidor.
